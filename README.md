# 🏋️ MOVE AI - Smart Gym & Activity Tracking App

MOVE AI is an advanced Android application built with Kotlin designed to assist users with workout routines, rep tracking, and real-time exercise monitoring.

---

## ✨ Features

* 🏋️ **Gym Activity Tracking:** Monitor workout sessions and track performance.
* 🤖 **Pose Detection & AI Integration:** Real-time movement analysis using camera features.
* 📊 **History & Analytics:** Keep track of past workouts and progress over time.
* 🎨 **Modern UI/UX:** Clean design implemented with Material Components and custom XML layouts.

---

## 🛠️ Tech Stack & Tools

* **Language:** Kotlin
* **Architecture / UI:** Android Views, Fragments, Material Components
* **Build System:** Gradle (Kotlin DSL `.kts`)
* **APIs & Libraries:** Coroutines, CameraX / Pose detection components

---

## 🚀 How to Run the Project

1. Clone the repository:
   ```bash
   git clone (https://github.com/Mohamed-Amine-Khaldi/move-ai.git)

1. Open the project folder in Android Studio.

2. Let Gradle sync successfully.

3. Connect an Android device (with USB debugging enabled) or start an Emulator, then click Run ▶.
